# 午午在线

面向城市白领工作日一人食的午餐决策助手 Demo。

“午午在线”嵌入在外卖平台首页中，用一次偏好设置替代每次重复筛选，再以 `TOP 1-3` 的可解释短名单帮助用户快速完成午餐决策。

> 本项目使用虚拟品牌“小王外卖”，仅用于产品概念展示，不涉及真实平台、商户或交易。

## 在线演示

- Demo：[https://stellular-tulumba-e85e05.netlify.app](https://stellular-tulumba-e85e05.netlify.app)

## 核心问题

工作日午餐的主要问题不是“附近没有店”，而是：

- 忌口、少油、主食、预算、配送时间和不重复等要求需要在多个筛选中来回切换。
- 商家和菜品高度同质化，列表越翻越长，用户迟迟无法作出决定。
- 推荐算法容易固化过去的选择，用户却不知道推荐依据。
- “健康”常被等同于高价轻食，无法覆盖正常饭菜少油一点的真实需求。

“午午在线”的策略是先收窄、再选择：优先排除硬性限制，再用用户偏好生成少量、可解释、可直接执行的选项。

## 用户链路

平台首页 → 进入“午午在线” → 首次设置偏好 → 规则长期生效  
→ 查看 3 个推荐 → 点“就这个” → 细粒度反馈 → 下次自动校准

## 关键功能

- **平台入口**：外卖首页提供高辨识度入口和“今天午饭吃什么？看这里！”提示。
- **首次偏好设置**：区分“不喜欢”和“过敏原”，支持自定义食材。
- **口味标签**：20 个标签按菜系、口味、成分、品牌分组，最多选择 5 个。
- **预算与重复频次**：支持预设预算、自定义价格区间和 2-3 天/一周不重复。
- **三选一短名单**：展示排名、推荐理由、用户评价、价格和预计送达时间。
- **细粒度反馈**：区分主菜类别、菜系、做法、店铺和单道菜。
- **反馈可解释**：反馈后说明调整范围，并即时补位、重新计算 TOP 顺序。
- **信任提示**：明确“按你的偏好排序，不是广告位”。

## 设计原则

1. 一次建立规则，长期复用。
2. 先排除，再收敛，不把无限列表交给用户。
3. 每条推荐必须说明“为什么适合你”。
4. 少油优先覆盖蒸、煮、炖、焖等正常做法，而不是只推轻食。
5. 负反馈必须限定作用范围，避免系统过度理解。
6. 推荐逻辑透明，排序不作为广告位。

## 技术实现

- 单文件静态 HTML：`outputs/index.html`
- 原生 HTML、CSS、JavaScript，无运行时依赖
- SVG 内嵌菜品插画和图标
- `localStorage` 保存偏好与首次设置状态
- 适配 `390×844` 手机视口、`320px` 窄屏及桌面预览

## 本地运行

直接打开：

```bash
open outputs/index.html
```

或通过静态服务器预览：

```bash
python3 -m http.server 8080 --directory outputs
```

然后访问 `http://localhost:8080`。

## 部署

项目使用 Netlify 托管，发布目录为 `outputs/`。

```bash
netlify deploy --dir outputs --no-build
netlify deploy --prod --dir outputs --no-build
```

`netlify.toml` 已指定静态发布目录，并为全站添加 `X-Robots-Tag: noindex, nofollow`。
